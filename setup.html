Setup Your Telegram Access

To use this app, you need your own Telegram API ID and API Hash. Your data stays in your Telegram account.

With the current setup, your session will expire after approximately 7 days.
When this happens, you’ll need to re-enter your API ID and API Hash to continue using the service.
You don’t need to create new ones — you can use the same API ID and API Hash.

Instructions

  1. Step 1: Click the button below to open Telegram developer site
  2. Step 2: Login with your phone number
  3. Step 3: Go to "API development tools"
  4. Step 4: Create a new app
  5. Step 5: Copy your API ID and API Hash
Security Notes
  • Your API credentials are securely handled
  • We do not store your files. Data stays in your Telegram account
